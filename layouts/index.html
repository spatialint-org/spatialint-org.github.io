Spatial Intelligence

Turn a geospatial question into a map.

Spatial Intelligence is an agent for geospatial analysis. Ask in plain language and get the analysis, a live map, and the files behind it — in one workspace.

How it works

From question to map.

1

Ask in plain language

Describe the place, the data, and the result you need. No tool sequence is required.

2

The agent does the work

It finds imagery, runs the analysis, and updates the map while it works.

3

Keep what it produces

The map, the data, and the run record stay together in a workspace you own.

Workspace

Your results stay yours.

Every analysis writes to a workspace on your machine: source imagery, results, the map project, and a record of the run.

  • Open outputs in QGIS, ArcGIS, or any standard raster or vector reader.
  • Review the run record to see what the agent did and why.
  • Run the app locally. Analysis data is not stored on our servers.
  • Use your own Python when no existing tool fits.
